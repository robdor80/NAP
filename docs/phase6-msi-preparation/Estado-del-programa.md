# B. Programa — entrega bloqueada

**No hay ejecutables ni paquete descargable en esta carpeta. No iniciar una prueba en el MSI.**

La publicación autónoma Windows x64 se verificó dentro del runner y se eliminó. Su manifiesto de 478 archivos y los hashes son evidencia de ese candidato retenido, no una descarga del programa ni autorización para ejecutarlo.

Bloqueos: transporte privado Actions→Drive sin validar; arranque ordinario sin aislamiento completo; textos/avisos de terceros y alcance de auxiliares pendientes. No usar artefactos públicos, una Release o un EXE aislado para sortearlos.

La opción de menor cambio de producto es decidir una edición interactiva exclusivamente sintética de solo lectura, sin arranque ordinario ni escrituras de configuración/raíces y con exportación encerrada. El canal requiere una identidad de transferencia con alcance mínimo autorizada por el titular; una alternativa cifrada estándar necesitaría diseño y prueba end-to-end. Ninguna está implementada ni debe darse por disponible.

Tras resolverlos se deberá regenerar el paquete desde el nuevo SHA, repetir las comprobaciones pertinentes y validar íntegramente la descarga desde Drive. No se puede reactivar el árbol efímero ya eliminado. La guía adjunta es condicional y detiene la prueba antes del lanzamiento mientras este estado siga bloqueado.
